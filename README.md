# wordle-app
Wordle на русском

Классическая игра Wordle на русском языке с поддержкой проверки слов через Яндекс Словарь API.

Основные функции:

    1. Русская раскладка - полная поддержка русской клавиатуры

    2. Разная длина слов - режимы на 4, 5 и 6 букв

    3. Два режима проверки:

        -Яндекс Словарь API (онлайн)

        -Локальный словарь (оффлайн)

Интеллектуальная подсветка:

    Зеленый - буква на правильном месте

    Желтый - буква есть в слове, но в другой позиции

    Серый - буквы нет в слове

Статистика игр - отслеживание побед и количества попыток

Режим для друзей - возможность загадать собственное слово

Структура экранов:
Главный экран (HomeScreen)

    Кнопка перехода к выбору режима

Выбор режима (ModeScreen):

    [4 буквы]
    [5 букв]
    [6 букв]
    [Загадайте другу]

Игровой экран (GameScreen)

    [Поле для ввода]
    [Клавиатура]

Экран с правилами(RuleScreen)

Экран со статистикой(StatScreen)

Диалог окончания игры:

    1. Поздравление при победе

    2. Показ загаданного слова при поражении

    3. Кнопки "Играть снова" и "В меню"


Особенности реализации:
  
    Проверка слов:
      -Онлайн режим: Яндекс Словарь API для точной проверки
      -Оффлайн режим: Локальный словарь из 10,000+ слов

    Автоматический fallback: При недоступности API переходит на локальную проверку

    Клавиатура:

        -Интеллектуальная подсветка использованных букв

        -Визуальная обратная связь

    Анимации:
        -Плавные переходы между экранами

        -Анимированное появление букв

        -Подсветка активной ячейки
